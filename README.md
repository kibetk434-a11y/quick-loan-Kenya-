# QuickLoan Kenya — Loan Website Starter

A mobile-friendly loan application website with:
- Loan calculator
- Customer application form
- Express backend
- SQLite database
- Application reference numbers
- Render-ready start command

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Deploy on Render

1. Upload this project to GitHub.
2. Create a new **Web Service** on Render.
3. Connect the GitHub repository.
4. Build command: `npm install`
5. Start command: `npm start`
6. Deploy.

## Important

This is a starter/demo application, not a licensed lending system. Before taking real customer money or issuing loans, add appropriate Kenyan legal/compliance requirements, privacy/security controls, identity verification, lender disclosures, terms, consent, secure authentication, audit logging, and a compliant payment provider.

The example 10% service charge is only a calculator placeholder and must not be represented as an actual lending rate or fee without proper disclosure and approval.
